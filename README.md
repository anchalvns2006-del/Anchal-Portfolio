### 1. OreSight AI

**AI & Satellite Intelligence for Manganese Exploration**

OreSight AI is an end-to-end intelligence platform designed to combine AI/ML and satellite-related insights for manganese exploration and production planning.

**Key capabilities:**

* Mineral prospectivity prediction
* Production forecasting
* Equipment risk analysis
* Satellite-related intelligence
* JWT authentication
* Role-based access
* Alerts and prediction history
* REST API backend

**Tech Stack:**
Python, FastAPI, React, Vite, Scikit-learn, SQLAlchemy, SQLite, JWT

**Model Results:**

* Prospectivity accuracy: ~94.6%
* Production forecasting R²: ~0.955
